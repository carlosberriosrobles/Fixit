# 🧑‍💻 Fixit – Página Web de Servicios de Soporte Informático

Bienvenido a **Fixit**, una página web creada para ofrecer servicios técnicos de calidad a personas y empresas que necesitan ayuda con sus dispositivos informáticos.

## 🌐 Descripción

Esta página tiene como objetivo presentar de forma profesional los servicios de soporte técnico que ofrecemos, tales como:

- 💿 Formateo e instalación de sistemas operativos
- 🛡️ Eliminación de virus y malware
- ⚙️ Optimización y limpieza de equipos lentos
- 📦 Instalación y configuración de programas
- 🔌 Configuración de redes y dispositivos

También cuenta con secciones de contacto y presentación de la empresa para que los usuarios puedan saber quiénes somos y cómo contratarnos.

---

## 📁 Estructura del Proyecto

```
📁 Fixit/
├── index.html            # Página principal
├── style.css             # Estilos CSS
├── script.js             # Lógica y animaciones en JavaScript
├── img/                  # Imágenes del sitio
└── README.md             # Este archivo
```

---

## 🧩 Tecnologías utilizadas

- **HTML5** – Estructura del contenido
- **CSS3** – Estilos personalizados
- **JavaScript** – Animaciones y funcionalidades interactivas
- *Visual Studio Code* – Editor recomendado para editar el proyecto

---

## ⚙️ Cómo abrir la página

1. Descarga todos los archivos en una carpeta local.
2. Haz doble clic en el archivo `index.html` para abrirlo en tu navegador.
3. También puedes usar la extensión **Live Server** de Visual Studio Code para ver los cambios en tiempo real.

---

## ✏️ Personalización

Puedes modificar fácilmente los textos, colores, imágenes y agregar más servicios editando los archivos:

- `index.html` para cambiar el contenido principal.
- `style.css` para modificar los estilos.
- `script.js` para agregar más efectos y funcionalidades.
